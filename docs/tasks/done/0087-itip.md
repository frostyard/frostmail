# T-0087: Read invitations and write answers

## Goal

`internal/itip`: find the iCalendar object in an invitation mail, read its
method and events, and write the user's answer two ways: the iTIP REPLY
that maild mails to an organizer when the server does not schedule, and
the PARTSTAT patch of the stored event when it does (ADR-0019). The
engine's `calendar.invitation` and `calendar.respond` build on it.

## Contract

- **FromMessage** walks the parts with `mimex.WalkParts` and returns the
  body of the first `text/calendar` part; when there is none, of the first
  part that is `application/ics` or has a filename ending in `.ics`
  (case-insensitive); else `ErrNoInvitation`.
- **Parse** reads the first VCALENDAR: `Method` from METHOD as the stub
  says (case-insensitive), `Source` the bytes given, `Events` from
  `calendar.Parse(src, opts)`. No usable VEVENT: `ErrNoEvent`. Not
  iCalendar: an error. `Main` returns the event without a recurrence ID,
  else the first.
- **Answers** are `accepted`, `declined` and `tentative` (PARTSTAT
  ACCEPTED, DECLINED, TENTATIVE); anything else is `ErrAnswer`, checked
  first.
- **Choosing the VEVENT:** with `recurrenceID` "", the VEVENT without a
  RECURRENCE-ID (else the first) for Reply, and every VEVENT for
  SetPartStat; otherwise the VEVENT whose `VEventRecurrenceID` equals it
  (none: `ErrNoOccurrence`).
- **The attendee** is the ATTENDEE whose value, without a `mailto:` prefix
  in any case, equals the address case-insensitively; none in the chosen
  VEVENT(s): `ErrNotInvited`. Its rewritten line keeps its value and
  every parameter as written, sets PARTSTAT (adding it when missing,
  in place when present) and drops RSVP.
- **Reply** writes, with CRLF line endings and every line folded at 75
  octets (`Prop.Encode`):
  - `BEGIN:VCALENDAR`, `VERSION:2.0`, a `PRODID`
    (`-//Frostyard//Frostmail//EN`), `METHOD:REPLY`;
  - each VTIMEZONE of the source whose TZID a copied DTSTART, DTEND or
    RECURRENCE-ID names, copied with its sub-components and lines as
    written (but CRLF);
  - one VEVENT with, in this order and copied as written when the source
    has them: UID, RECURRENCE-ID, SEQUENCE, DTSTART, DTEND, DURATION,
    SUMMARY, ORGANIZER; then `DTSTAMP` (`now` in UTC,
    `20060102T150405Z`), the attendee's line, and `COMMENT` (escaped with
    `EscapeText`) when the comment is not empty. Nothing else: no other
    attendees, no DESCRIPTION, alarms or X- properties.
- **SetPartStat** replaces only the attendee's ATTENDEE line in each
  chosen VEVENT, re-encoded in the source's line ending
  (`LineEnding`), with `contentline.Apply`; every other byte stays.
  None of the chosen VEVENTs names the attendee: `ErrNotInvited`.
- **ForCalendar** removes the VCALENDAR's METHOD line and nothing else;
  without one the source comes back unchanged.

## Gotchas

- `contentline.Prop.Start`/`End` cover the folded line with its line
  ending: replacing that range replaces the whole property.
- A VTIMEZONE's bytes are `src[c.Start:c.End]`; normalize its line
  endings to CRLF when copying.
- Compare addresses lowercased, but write them as the source does.
- Keep functions under 60 lines.

## Out of scope

(`calendar.invitation` and `calendar.respond`), and every file not under
`touch`.
